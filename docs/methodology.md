# 指标口径与方法论

这份文档定义每个指标的**精确算法**。代码和文档不一致时，以本文档为准，改代码。

---

## 1. KDJ

### 算法

```text
N = 9, M1 = 3, M2 = 3（通达信 / 东财默认）

LLV = 最近 N 根 K 线的最低价的最小值
HHV = 最近 N 根 K 线的最高价的最大值

RSV_t = (C_t - LLV_t) / (HHV_t - LLV_t) × 100
K_t   = ((M1 - 1) × K_{t-1} + RSV_t) / M1     K_0 = 50
D_t   = ((M2 - 1) × D_{t-1} + K_t)   / M2     D_0 = 50
J_t   = 3 × K_t - 2 × D_t
```

### 关键约定

| 项 | 约定 | 理由 |
|---|---|---|
| 复权 | **前复权 fqt=1** | 不复权时除权日跳空会产生巨大假死叉 |
| K/D 平滑 | 递推，权重 1/M | 通达信口径。用 `rolling().mean()` 会差 10~20 |
| 初值 | K=D=50 | 通达信口径。用 0 会让前 30 根整体偏低 |
| 历史长度 | ≥ 120 根 | 初值影响衰减 (2/3)^30 ≈ 5e-6，120 根足够收敛 |
| HHV == LLV | RSV = 100 | 一字板，分母为 0。不处理会得到 NaN |
| RSV 范围 | 裁剪到 [0, 100] | 防止浮点误差导致越界 |
| 数据不足 | 返回 None | **不能返回 0**，J=0 会被读成超卖 |
| 输出精度 | 2 位小数 | Excel 展示口径 |

### 十个周期的取值

| 表头 | 数据源 | 位置 |
|---|---|---|
| 上一月 / 本月 | 月线 klt=103 | 倒数第 2 / 第 1 根 |
| 上一周 / 本周 | 周线 klt=102 | 倒数第 2 / 第 1 根 |
| 上一日 / 本日 | 日线 klt=101 | 倒数第 2 / 第 1 根 |
| 120 分钟 | 60 分钟合成 | 最后 1 根 |
| 60 / 30 / 15 分钟 | klt=60 / 30 / 15 | 最后 1 根 |

「本月/本周/本日」是**尚未走完的周期**，盘中随行情变动。
午盘批和收盘批的「本日」必然不同，这是定义决定的。

### 120 分钟合成规则

```text
A股每日 4 根 60 分钟线：10:30 / 11:30 / 14:00 / 15:00
按交易日分组，每 2 根合成 1 根：

时间戳 = 后一根的时间戳
开盘   = 前一根的开盘
收盘   = 后一根的收盘
最高   = max(两根最高)
最低   = min(两根最低)
成交量 = 两根之和
```

盘中若下午只有 1 根（如 14:00），保留这半根 —— 那正是"当前 120 分钟周期"。

## 2. 成交量变异系数

### 算法

```text
CV = 样本标准差(ddof=1) / 均值
```

| 指标 | 窗口 | 定义 |
|---|---|---|
| 过去 20 日 CV | `vol[-20:]` | 近期活跃度 |
| 过去 30 日 CV | `vol[-30:]` | 中期活跃度 |
| 过去 40~10 日 CV | `vol[-40:-10]` | **基准期**活跃度（30 根） |
| 放量倍数 | `max(vol[-10:]) / mean(vol[-40:-10])` | 异动强度 |
| 成交量标准差 | `std(vol[-30:], ddof=1)` | 附加参考，有量纲，不可横向比较 |

### 关键约定

| 项 | 约定 | 理由 |
|---|---|---|
| 标准差 | 样本标准差 ddof=1 | 我们看的是样本不是总体 |
| 基准期 | 排除最近 10 天 | **异动不能污染自己的基准**，否则倍数被稀释 |
| 均值 ≤ 0 | 返回 None | 长期停牌 |
| 样本 < 2 | 返回 None | 无法算标准差 |
| 历史不足 | 返回 None | **不用更短窗口凑数**，小样本 CV 方差过大 |
| 输出精度 | 4 位小数 | |

### 为什么用 CV 而不是标准差

CV 是无量纲的，所以能跨股票横向排序。
标准差带量纲，茅台的 5 万手和小盘股的 5 万手不是一回事。

### 组合使用

```text
基准期 CV 低 + 放量倍数高 = 真异动（平时安静，突然放量）
基准期 CV 高 + 放量倍数高 = 常态（平时就闹）
```

单看倍数会被题材股刷屏。

## 3. 咨询量

### 口径

需求原文的"咨询量"没有官方统计口径，本项目定义为：

```text
咨询量 = 东方财富全站资讯检索，按股票名称命中的文章条数
```

| 窗口 | 定义 |
|---|---|
| 近期 | 过去 48 小时，换算日均 = 条数 / 2 |
| 基准 | 48 小时之前往前 14 天，日均 = 条数 / 14 |
| 升温倍数 | 近期日均 ÷ 基准日均 |

### 已知偏差（必须随表输出）

| 偏差 | 影响 | 缓解 |
|---|---|---|
| 转载重复计数 | 衡量的是媒体覆盖广度，非讨论人次 | 只做横向比较，不看绝对值 |
| 同名误命中 | 名称含通用词的公司被污染 | 表里保留原始条数，异常值人工核对 |
| 翻页截断 400 条 | 最热的股票倍数被低估 | 「是否触顶截断」列显式标记 |
| 基准期样本过小 | 2 条变 20 条 = 10 倍，无意义 | 保留「基准期条数」列，< 5 直接跳过 |

### 候选池

全市场约 2.2 万次请求会被限流。默认沪深300。
实践中最有用的是 `watchlist` 模式：先用需求 1、2、4 筛出候选，只查这几十只。

## 4. 板块热度

### 口径

```text
板块热度 = 该板块当日主力净流入额 / 全市场当日主力净流入总额

全市场 = 沪深两市【全部个股】主力净流入逐只求和
```

### 分母必须逐只求和（这一条曾经写错，2026-08-08 修正）

**本文档早期版本写的是「全市场 = 所有行业板块之和」，理由是「东财行业板块对 A 股
是完整划分，每只股票恰好归属一个行业板块」。实测推翻了这个假设。**

东财 `m:90 t:2` 返回 **496 个行业板块，一级/二级/三级混在一起并列返回**：

```text
电子(423只)  元件(62只)  印制电路板(48只)  半导体(174只)  医药生物(467只) ...
```

「元件」「印制电路板」「半导体」都是「电子」的子板块。
496 个板块的成分股数合计 **8679**，而全市场只有 **5547** 只 —— 重复计算了。

实测三种口径（2026-08-07）：

| 口径 | 分母 | 相对正确值 |
|---|---|---|
| 全市场个股逐只求和 | 364.4 亿元 | **1.00×（正确）** |
| 496 个行业板块求和 | 1090.5 亿元 | 2.99× |
| 504 个概念板块求和 | 6216.1 亿元 | 17.06× |

用错分母**不会报错**，只会让所有占比系统性低估 67%。
这是"口径错误比程序崩溃更危险"最好的教学案例。

正确做法：`clist` 按 `fields=f12,f62` 分页拉全市场个股，f62 求和。56 次请求。

### 历史数据从哪来：本地按日快照

需求要 A-3 / A-2 / A-1 / A 四天，但**没有接口能稳定给到多日**：

| 接口 | 实测行为 |
|---|---|
| `push2his` 的 fflow | 能给 10 天，但**间歇性** —— 同一分钟内时通时断 |
| `push2delay` 的 fflow | 稳定，但不管 `lmt` 传多少都只给最新 1 天 |
| 个股资金流（分母） | 只有当日，无历史接口 |

所以改成本地累积：每个交易日运行时把当天的板块流入 + 全市场基准存进
`data/flow_history/YYYY-MM-DD.json`，历史自己攒（见 `radar/flow_history.py`）。

比依赖单次请求可靠 —— 某天接口抽风只丢那一天，不会让整张表出不来。
首次部署时若 `push2his` 恰好通，会顺手回填几天（回填日没有分母，那几格留空）。

### 关键约定

| 项 | 约定 | 理由 |
|---|---|---|
| 分母 | 全市场个股逐只求和，取绝对值 | 净流出时分母为负，abs 保证符号只反映板块自身方向 |
| 输出 | 4 个交易日 A-3 / A-2 / A-1 / A | 看趋势不看水平 |
| 交易日 | 以本地快照为准 | |
| 排序 | 按今日占比降序，无数据沉底 | |
| 占比之和 | ≠ 100%（实测约 1700%） | 概念板块互相重叠 |
| 负值 | 该板块净流出 | |
| 空格 | 该日缺分母（回填日）或该板块当天无数据 | |

### 读表注意：属性类板块会霸榜

概念板块里混着「融资融券」「沪股通」「百元股」「MSCI中国」这类**属性标签**，
覆盖大半个市场，占比必然排最前（实测融资融券 99.9%、沪股通 59.0%）。

学员关心的是「创新药 / 储能 / 光模块 / AI应用」这类**题材板块**，
读表时要跳过属性类，或在筛选条件里排除。

### 为什么看占比而非绝对额

全市场资金总量每天在变。同样净流入 20 亿：
大盘净流出时说明资金在逆势集中（信号强），大盘普涨时可能只是被动跟随（信号弱）。
占比剥离了大盘背景。

## 5. 股票池

| 项 | 约定 |
|---|---|
| 范围 | 上交所主板 + 科创板 + 深交所主板 + 创业板 |
| 北交所 | 默认剔除（需求写的是"深沪两市"） |
| 停牌 | 默认剔除（最新价为 0） |
| ST | 默认保留（`exclude_st = False`，需要时可开） |
| 去重 | 按 secid 去重（东财分页边界偶有重复） |
| 排序 | 按代码升序，保证两次运行行序一致 |

## 修改本文档的规则

1. 先改文档，说清楚新口径和理由。
2. 再改代码。
3. 补或改单元测试（`tests/test_indicators.py`）。
4. 跑 `--limit 30` 验证。
5. 在 Excel 的「口径说明」页同步更新。

**口径变更必须在报表里可见。** 三个月后对不上数时，能查到是哪天改的。
