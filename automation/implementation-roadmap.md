# 实现路线图

## 阶段 1：数据链路跑通 ✅ 已完成

目标：能从东财拉到数据，算出正确的指标，输出符合需求表头的 Excel。

已做：

1. HTTP 层：令牌桶限流 + 指数退避重试 + 磁盘缓存
2. 全市场股票池（沪深两市，剔除北交所和停牌）
3. 六个周期 K 线抓取 + 120 分钟合成
4. KDJ(9,3,3) 通达信口径，含一字板、初值、数据不足的处理
5. 成交量变异系数与放量倍数
6. 板块资金流历史与全市场基准
7. 资讯检索与咨询量统计
8. 四张 Excel（含两行合并表头 + 口径说明页）
9. 11 个指标单元测试，不依赖网络
10. 命令行入口，支持 `--task` `--limit` `--concurrency` 等

验收：

- `python3 tests/test_indicators.py` 11 个测试全绿 ✅
- Excel 表头 32 列、12 个合并区、J=3K-2D ✅
- `python3 run.py --task 1 --limit 30` 能出文件 ⏳ **待联网验证**

## 阶段 2：真实数据验证 ⏳ 进行中

目标：确认算出来的数和东财 App 一致。

要做：

1. 联网跑 `--limit 30`，确认无异常
2. 挑 5 只股票，把日线 KDJ 和东财 App 的 KDJ(9,3,3) 手工对照
3. 确认 120 分钟合成结果和东财的 120 分钟图一致（如果 App 有）
4. 确认成交量 CV 用 Excel 手算一只验证
5. 确认板块占比的分母口径合理（抽查一天，看总额量级是否符合常识）
6. 跑一次全市场，记录耗时和失败率作为基线

验收：

- 5 只股票的日线 KDJ 差值 < 0.05
- 全市场跑通，失败 < 100 只，耗时 < 20 分钟
- 四个文件都生成，口径说明页信息完整

**这个阶段不能跳过。** 指标算错了不会报错，只会安静地给出错误结论。

## 阶段 3：定时运行

目标：让系统自己跑起来。

要做：

1. `./scripts/install_launchd.sh install`
2. 观察第一个交易日的两个批次
3. 周末验证交易日闸门（应该退出码 2）
4. 检查日志轮转和文件清理是否生效

验收：

- 连续 10 个交易日无人工干预自动出表
- 失败率稳定在 100 只以内
- 非交易日正确跳过

## 阶段 4：候选池闭环

目标：把 学员的筛选动作也固化下来。

要做：

1. 建立 `data/watchlist.txt` 自选池
2. 需求 3 改用 watchlist 模式（更快更准，避开限流）
3. 增加一个「候选池汇总」sheet：把四张表按代码合并成一行
4. 记录每日候选池快照，供周复盘对比

验收：

- 从四张表到候选池的操作从 20 分钟缩短到 5 分钟
- 能回看任意一天的候选池

## 阶段 5：历史积累与复盘

目标：让数据能回答"我的筛选标准好不好"。

要做：

1. 每日快照落库（parquet 或 sqlite，Excel 不适合做历史查询）
2. 候选池表现追踪：选出后 5 日 / 10 日的涨跌
3. 周复盘报表：命中率、漏掉的、误选的
4. 参数版本记录：每次调整筛选条件都留档

验收：

- 能回答"上个月的筛选标准，命中率是多少"
- 能对比两个版本筛选条件的差别

## 阶段 6（第三部分课程）：Agent 化

目标：从"看表"变成"对话"。

要做：

1. 把四张表接成 Agent 可读的结构化数据
2. 自然语言查询："今天有哪些板块连续 3 天资金流入且里面有放量股"
3. 自动生成每日盘后简报
4. 根据复盘结果建议参数调整

**这个阶段的前提是阶段 5 的历史数据已经积累够。** 顺序不能反。
