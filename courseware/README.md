## 讲课时反复强调的六句话

1. **表头就是需求。** Excel 模板是最精确的需求文档。
2. **算得快不如算得对。** 先 `--limit 30` 验证，再跑 5500 只。
3. **空值必须留空，不能填 0。** J 值填 0 会被读成超卖。
4. **本周期是活的。** 午盘批和收盘批的「本日」不一样，这是特性。
5. **指标不是信号。** 雷达的产出是候选池，不是决策。
6. **每天先看失败数。** 失败几百上千的那天，数据不能用。

## 第一部分的验收标准

```text
连续 10 个交易日无人工干预自动出表，且失败率稳定在 100 只以内。
```

跑通一次不算完成。第一部分交付的是一条**能长期运行的流水线**。
