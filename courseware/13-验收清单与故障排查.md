## 常见问题

### 1. 一个文件都没生成，日志里全是请求失败

先分清是网络问题还是代码问题：

```bash
# 手工验证接口通不通
curl -s -o /dev/null -w "%{http_code}\n" \
  'https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=2&po=1&np=1&fltt=2&invt=2&fid=f12&fs=m:1+t:2&fields=f12,f14'
```

| 返回 | 含义 | 处理 |
|---|---|---|
| 200 | 接口正常 | 代码/环境问题，往下查 |
| 502 / 000 | 到不了东财 | 检查本机代理（如 Clash）是否正常 |

如果本机走代理，Python 默认会读 `HTTP_PROXY` 环境变量。代理挂了就全线失败。
可以临时关掉代理再试：

```bash
RADAR_USE_PROXY=0 python3 run.py --task 1 --limit 10
```

### 2. 手动跑没问题，launchd 定时跑就失败

**最常见的原因是 PATH。** launchd 的环境变量和终端不一样。

```bash
# 看 launchd 层的日志
cat data/logs/launchd.close.err.log
```

确认 plist 里的 `PATH` 包含 python3 所在目录。
`scripts/install_launchd.sh` 里已经写好了，但如果换了 Python 版本要同步改。

### 3. 失败数突然从几十涨到几百上千

说明接口层面出问题了。按顺序查：

1. 手工 curl 验证接口还通不通
2. 如果通，看是不是被限流了 —— 把 `concurrency` 调到 6，`qps_limit` 调到 15 再试
3. 如果还不行，可能是东财改了接口字段，用 curl 看返回的 JSON 结构

**这一天的数据不要用。**

### 4. KDJ 和东财 App 对不上

按这个顺序查：

| 检查项 | 正确做法 |
|---|---|
| 复权方式 | 必须 `fqt=1` 前复权。不复权的话除权日会出巨大假死叉 |
| 平滑算法 | 递推 `K=(2K+RSV)/3`，不是 `rolling(3).mean()` |
| 初值 | K、D 初值都是 50，不是 0 |
| 历史长度 | `kline_limit` 至少 120，太短则初值残影没衰减掉 |
| 字段顺序 | `f52,f53,f54,f55` 是 **开、收、高、低**，不是开高低收 |

差 0.01~0.05 是正常的（App 拉的历史长度和四舍五入位置不同）。

### 5. 「本日」的 KDJ 上午和下午不一样

**这是对的，不是 bug。**

「本日/本周/本月」指的是当前尚未走完的周期。午盘批（11:40）拿到的是半天的数据，
收盘批（15:15）才是完整的一天。同理「本周」在周三和周五也不一样。

### 6. 需求 3 跑得特别慢或大量失败

搜索接口比行情接口脆弱得多。

```bash
# 别跑全市场
python3 run.py --task 3 --sentiment-universe hs300       # 约 3 分钟
python3 run.py --task 3 --sentiment-universe watchlist   # 最快，也最实用
```

全市场模式（`all`）约 2.2 万次请求，会被限流，要预留 1 小时以上。

### 7. 板块占比之和不等于 100%

**正常。** 概念板块互相重叠，一只股票可以同时属于几十个概念板块。
如果想要一个能加总到 100% 的口径，用行业板块：

```bash
python3 run.py --task 4 --sector industry
```

### 8. Excel 打不开筛选

需求 1 是两行合并表头，**必须选中第 2 行**（K值/D值/J值 那一行）再开筛选。
选第 1 行会因为合并单元格而失败。

### 9. 想改指标但怕改坏

```bash
# 改之前先跑一遍，记住基线
python3 tests/test_indicators.py

# 改完再跑，11 个必须全绿
python3 tests/test_indicators.py

# 然后小规模验证
python3 run.py --task 1 --limit 30
```

改动指标算法而测试还全绿，说明测试覆盖不够 —— 这时候应该先补测试。

## 每日健康检查（30 秒）

```bash
cd /path/to/a-share-radar   # 换成你的克隆目录
ls -la data/output/ | grep $(date +%Y%m%d)
grep -E "扫描完成|完成，耗时" data/logs/run_$(date +%Y%m%d).log
```

| 指标 | 正常 | 异常 |
|---|---|---|
| 文件数（收盘批） | 4 个 | 少于 4 个 |
| 失败数 | < 100 只 | > 500 只 → 当天数据不可用 |
| 耗时 | 4~10 分钟 | > 20 分钟 → 调低并发 |
