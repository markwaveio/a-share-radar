# 08 Excel 报表与阅读方法

## 表头就是需求

需求 1 的表头是两行合并结构 —— 这不是排版偏好，是**验收标准**：

```text
第 1 行：个股代码 | 个股名称 | 上一月(合并3列) | 本月(3) | ... | 15分钟(3)
第 2 行：                    |  K值 D值 J值   | K值 D值 J值 | ...
```

一共 2 + 10×3 = **32 列**，12 个合并区（代码 + 名称 + 10 个周期）。

可以现场验证：

```python
from openpyxl import load_workbook
ws = load_workbook("data/output/01_KDJ全周期_20260807_close.xlsx")["KDJ全周期"]
print(ws.max_column)                  # 32
print(len(ws.merged_cells.ranges))    # 12
```

**教学点**：需求方给的表格模板，往往就是最精确的需求文档。
拿到项目先照着表头把输出结构定死，比读十页文字描述有效。

## 每份文件都带「口径说明」页

四个 Excel 都有一个 `口径说明` sheet，写清楚：

- 生成批次、样本数、失败数、耗时
- 数据源和参数（KDJ 用了 9,3,3、前复权）
- 每个指标的精确定义
- 空值代表什么
- 已知偏差是什么

**为什么必须放在文件里而不是只写在文档里**：
Excel 会被转发给别人。文档不会跟着走，口径说明会。
三个月后 你自己回看这个文件，也需要这一页。

## 冻结窗格与列宽

- 需求 1 冻结在 `C3`：往右滚看 15 分钟时，代码和名称还在
- 需求 2/3/4 冻结在 `A2`
- 数值列统一 `0.00` 或 `0.0000` 格式，板块占比用百分比格式

这些细节决定 你每天愿不愿意打开它。

## 每张表的日常操作

### 01 KDJ全周期

```text
筛选：选中第 2 行 -> 数据 -> 筛选
常用：本日J值 < 20 且 本周J值 < 30 且 本月J值上升
排序：按「本日_J」升序找超卖，降序找超买
```

因为是合并表头，Excel 的自动筛选要**选中第 2 行**再开，不能选第 1 行。
这个操作要在第一次操作时留意。

### 02 成交量异动

日常只看「放量TOP200」页。已经按放量倍数降序排好了。
加一列自定义筛选：`过去40~10日CV < 0.6`。

### 03 咨询量变化

只看「升温TOP100」。先看「基准期条数」列，小于 5 的整行跳过。
再看「是否触顶截断」，标『是』的说明倍数被低估，值得单独看。

### 04 板块热度

已按今日占比降序。**要看的是四列的趋势**，不是单看最后一列。
选中四列占比 -> 插入迷你图（折线），一眼看出哪些板块在持续升温。

## 命名规则

```text
01_KDJ全周期_20260807_close.xlsx
│   │         │        └─ 批次：midday 午盘 / close 收盘 / manual 手动
│   │         └─ 日期
│   └─ 需求名
└─ 需求编号
```

同一天的午盘批和收盘批是**两个文件，不互相覆盖**。
这样才能对比"半天"和"全天"的差别，也保留了盘中快照。

## 数据保留策略

`scripts/run_radar.sh` 里自动清理：

- 日志保留 30 天
- Excel 保留 60 天

要长期留档，把文件另存到别的目录，或者改脚本里的 `-mtime` 参数。

## 一个必须建立的习惯

**每次打开表，先看「口径说明」页的"抓取失败"数。**

正常应该是几十只以内（停牌、新股）。
如果某天突然变成几百上千，说明接口出问题了，**当天这份数据不能用**。

这个习惯比任何指标都重要。
