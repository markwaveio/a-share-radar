# 05 KDJ 多周期指标（需求 1）

## KDJ 是什么

一句话：**收盘价在最近 N 天的价格区间里处于什么位置**，再做两层平滑。

```text
RSV = (今日收盘 - 最近9日最低) / (最近9日最高 - 最近9日最低) × 100
K   = (2 × 前一日K + 今日RSV) / 3        初值 50
D   = (2 × 前一日D + 今日K)   / 3        初值 50
J   = 3K - 2D
```

- RSV = 100 → 收盘正好在 9 日最高点
- RSV = 0   → 收盘正好在 9 日最低点
- J 值放大了 K 和 D 的差，所以 J 会跑出 0~100 之外，这是正常的

## 三个必须讲透的坑

### 坑 1：这里的"平滑"不是移动平均

`K = (2×K_prev + RSV) / 3` 是**递推平滑**，不是 `rolling(3).mean()`。

可以直接演示两种算法算出来的差别 —— 通常差 10~20，
而且用错了以后所有周期全错，但看起来"像是对的"。

代码里的注释专门标了这一点：

```python
# radar/indicators.py
# 这里的 SMA 是通达信的"移动平均"，不是简单均值，而是权重 1/m 的递推平滑；
# 用 pandas 的 rolling().mean() 会算出完全不同的值。
```

### 坑 2：K 和 D 的初值是 50，不是 0

因为是递推的，第一根 K 线的 K = (2×50 + RSV)/3。
初值影响会随时间衰减：30 根之后衰减到 (2/3)³⁰ ≈ 5×10⁻⁶，可以忽略。

**所以要多拉历史**。项目里 `kline_limit = 120`，就是为了让前面的初值影响衰减干净。
如果只拉 10 根 K 线算 KDJ，算出来的全是初值 50 的残影。

### 坑 3：一字板会除以 0

涨停一字板时最高价 = 最低价，RSV 的分母是 0。
代码里的处理是：此时 RSV 记为 100。

```python
rsv = np.where(span == 0, 100.0, ...)
```

不处理的话会得到 NaN，然后整只股票的 KDJ 全是空。

## 十个周期怎么取值

表头里的「上一月 / 本月」不是两个指标，是**同一条月线序列上的倒数第 2 根和倒数第 1 根**。

```python
# radar/config.py
("上一月", 103, -2),   # 月线，倒数第 2 根
("本月",   103, -1),   # 月线，倒数第 1 根
```

**「本月/本周/本日」是活的** —— 当前周期还没走完，盘中一直在变。
这意味着午盘批和收盘批的「本日」KDJ 必然不同。这是特性不是 bug。

## 120 分钟怎么来的

东财原生周期里没有 120 分钟，需求又要，所以用 60 分钟合成：

```text
A股每天交易 4 小时 = 4 根 60 分钟线（10:30 / 11:30 / 14:00 / 15:00）
每 2 根合成 1 根 120 分钟：
    上午：10:30 + 11:30 -> 时间戳 11:30
    下午：14:00 + 15:00 -> 时间戳 15:00
合成规则：开盘取前一根、收盘取后一根、最高取两根最大、最低取两根最小、成交量相加
```

盘中运行时下午可能只有 1 根（比如 14:00），这时保留这半根不完整的 —— 那正是"当前 120 分钟周期"。

## 多周期共振怎么用

| 组合 | 含义 |
|---|---|
| 月 + 周 + 日 J 值都从低位往上 | 三层共振，最强的信号形态 |
| 月线 J 高位、日线 J 低位 | 大趋势在高位调整，反弹级别有限 |
| 只有 15/30 分钟金叉 | 日内噪音，单独用没有筛选价值 |

动手验证：从当天的表里各找一个例子，打开东财 App 看图对照。

## 空值的含义

新股或长期停牌的股票，某些周期 K 线数量不足，输出留空。

**绝对不能填 0。** J 值 0 会被读成"极度超卖"，这是会导致真实亏损的错误。
代码里 `kdj_at()` 数据不足时返回 `(None, None, None)`，测试里专门锁死了这个行为。
