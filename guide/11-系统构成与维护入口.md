# 11 系统构成与维护入口

## 系统构成

| 部分 | 作用 |
|---|---|
| 东方财富公开接口 | 唯一数据源：行情、K 线、板块资金流、资讯检索 |
| `radar/http.py` | 限流、重试、缓存 —— 3.3 万次请求能不能跑完取决于它 |
| `radar/universe.py` | 全市场股票池，分页拉取 + 过滤 |
| `radar/kline.py` | K 线抓取 + 120 分钟合成 |
| `radar/indicators.py` | KDJ 与成交量 CV —— 唯一不能出错的地方 |
| `radar/scan.py` | 全市场并发扫描，需求 1、2 共用 |
| `radar/sectors.py` | 板块清单与资金流历史 |
| `radar/sentiment.py` | 资讯检索与咨询量统计 |
| `radar/excel.py` | 两行合并表头的 Excel 输出 |
| `radar/trading_calendar.py` | 交易日判断（问上证指数，不维护本地节假日表） |
| `run.py` | 命令行入口 |
| `scripts/run_radar.sh` | launchd 调用的批次脚本 |
| launchd | 定时触发（11:40 / 15:15） |

## 数据流向

```text
universe.py  拉股票池
      ↓
scan.py      每只股票并发 → kline.py 拉 6 个周期
      ↓                          ↓
      ↓                    resample_120m 合成 120 分钟
      ↓                          ↓
      └──────→ indicators.py 算 KDJ / CV
                     ↓
              tasks/task1_kdj.py     → 01_KDJ全周期.xlsx
              tasks/task2_volume.py  → 02_成交量异动.xlsx

sectors.py   → tasks/task4_sector.py    → 04_板块热度.xlsx
sentiment.py → tasks/task3_sentiment.py → 03_咨询量变化.xlsx
```

## 维护入口

| 要改什么 | 改哪里 |
|---|---|
| KDJ 参数、CV 窗口、并发数、候选池 | `radar/config.py` |
| 十个周期的定义和顺序 | `radar/config.py` 的 `TIMEFRAME_COLUMNS` |
| Excel 表头文字 | `radar/tasks/task*.py` 的 `HEADERS` |
| 定时时间 | `scripts/install_launchd.sh` 里的 `make_plist` 调用 |
| 午盘批跑哪些任务 | `scripts/run_radar.sh` 的 `case` 分支 |
| 自选股清单 | `data/watchlist.txt`（每行 `代码,名称`） |
| 日志/报表保留天数 | `scripts/run_radar.sh` 末尾的 `-mtime` |

## 常用命令

```bash
cd /path/to/a-share-radar   # 换成你的克隆目录

# 链路自检（30 只，约 20 秒）
python3 run.py --task 1 --limit 30

# 单独跑某个需求
python3 run.py --task 2
python3 run.py --task 4 --sector industry
python3 run.py --task 3 --sentiment-universe watchlist

# 指标测试（不需要网络）
python3 tests/test_indicators.py

# 交易日判断
python3 -m radar.trading_calendar

# 缓存
python3 run.py --clear-cache

# 定时任务
./scripts/install_launchd.sh install|status|uninstall

# 手动跑一次批次（和 launchd 走同一条路径）
./scripts/run_radar.sh close
```

## 维护原则

- **改指标必须重跑测试。** `python3 tests/test_indicators.py`，11 个测试全绿才算改完。
- **改完先跑 `--limit 30`**，确认能出文件，再跑全市场。
- **不要直接改 `data/output/` 里的 Excel**。下次运行会生成新文件，改动会丢。
  要加工就另存到别的目录。
- **不要为了跑得快无限调高并发。** 被限流之后重试反而更慢，而且对数据源不礼貌。
- **接口失效时不要硬扛。** 失败率突然飙升，先确认是不是接口改了，
  改代码之前先用 curl 手工验证一次。
- **不接交易接口。** 这条是项目边界，不是技术选择。

## 备份什么

| 内容 | 要不要备份 | 说明 |
|---|---|---|
| `radar/` `run.py` `scripts/` | 要 | 代码，建议进 git |
| `courseware/` `docs/` | 要 | 手册和方法论 |
| `data/watchlist.txt` | 要 | 自选池，是 你的积累 |
| `data/output/` | 选择性 | 想做长期回溯就留，否则 60 天自动清 |
| `data/cache/` | 不要 | 临时文件 |
| `data/logs/` | 不要 | 30 天自动清 |
