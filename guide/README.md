## 六条要点

1. **表头就是需求。** Excel 模板是最精确的需求文档。
2. **算得快不如算得对。** 先 `--limit 30` 验证，再跑全市场。
3. **空值必须留空，不能填 0。** J 值填 0 会被读成"超卖"。
4. **本周期是活的。** 午盘批和收盘批的「本日」不一样，这是定义决定的。
5. **指标不是信号。** 产出是候选池，不是决策。
6. **每天先看失败数。** 失败几百上千的那天，数据不能用。
