# 06 成交量异动识别（需求 2）

## 为什么用变异系数，不用成交量本身

成交量的绝对值不能横向比较：贵州茅台一天成交 3 万手，某小盘股 3 万手，含义完全不同。

**变异系数 CV = 标准差 / 均值**，把量级除掉了，剩下的是"波动的相对幅度"，
所以可以拿 5500 只股票放在一起排序。这是它比标准差好用的唯一原因，但也是决定性的原因。

```text
标准差：这只股票成交量波动 5 万手      -> 无法比较
CV   ：这只股票成交量波动是均值的 0.3 倍 -> 可以比较
```

## 四个指标分别看什么

| 指标 | 窗口 | 看什么 |
|---|---|---|
| 过去 20 日 CV | 最近 20 天 | 近期活跃度 |
| 过去 30 日 CV | 最近 30 天 | 中期活跃度 |
| 过去 40~10 日 CV | 40 天前到 10 天前 | **平时**有多活跃（基准） |
| 放量倍数 | 最近 10 日最大量 ÷ 基准期均量 | 最近这一下有多突然 |

## 关键设计：基准期为什么要排除最近 10 天

这是最重要的一点。

```text
错误做法：放量倍数 = 最近10日最大量 / 过去40日平均量
问题：    过去40日里包含了最近10天的放量，分母被自己抬高，倍数被稀释
```

```text
正确做法：放量倍数 = 最近10日最大量 / 过去(40~10)日平均量
理由：    基准期必须是"异动发生之前"的干净样本
```

可以举个数字例子：

| | 前 30 天日均量 | 最近 10 天最大量 | 含 vs 不含最近10天 |
|---|---|---|---|
| 数据 | 100 | 1000 | — |
| 排除最近10天 | 分母 100 | 分子 1000 | **倍数 10** |
| 不排除 | 分母 (100×30+1000×10)/40 = 325 | 分子 1000 | 倍数 3.1 |

同一件事，一个报 10 倍，一个报 3.1 倍。这就是口径的重要性。

这条逻辑在测试里锁死了：

```python
# tests/test_indicators.py
def test_volume_range_window_excludes_recent_days():
    volumes = [100] * 40 + [1000] * 10
    assert m["cv_range"] == 0.0        # 基准期必须干净
    assert abs(m["spike_ratio"] - 10.0) < 1e-6
```

## 怎么组合使用：CV 和倍数必须一起看

单看放量倍数会被题材股刷屏。正确的组合是：

```text
基准期 CV 低（平时安静） + 放量倍数高（突然放量） = 真异动
基准期 CV 高（平时就闹） + 放量倍数高            = 常态，信息量低
```

在 Excel 里的操作：先按放量倍数降序，再筛 `过去40~10日CV < 0.6`。

## 为什么用样本标准差（ddof=1）

```python
s.std(ddof=1)   # 除以 n-1，不是 n
```

因为我们看到的是**样本**（最近 N 个交易日），不是这只股票全部历史。
差别在小样本时才明显（n=20 时约 2.6%），但口径必须写死并写进文档，
否则换个人重算会对不上。

## 空值的处理

上市不足 40 个交易日的新股，基准期窗口取不满，直接给空值。

**不要用更短的窗口凑数**。样本从 30 个降到 5 个，CV 的方差会大到没有意义，
但表格里看起来和别的数一样"正常" —— 这种静默失真比留空危险得多。
