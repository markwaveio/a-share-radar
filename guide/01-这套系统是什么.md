# 01 这套系统是什么

## 一句话

**把你的选股筛选标准固化成每日自动报表**的数据流水线。

目标不是预测涨跌，而是把"从 5200 只股票里找出值得看的那几十只"这件事，
从每天两小时的人工翻页，变成盘后打开一个 Excel。

## 它解决什么

| 你现在的做法 | 换成 |
|---|---|
| 想看全市场 KDJ，软件只能一只一只翻 | 一次输出 5200 只 × 10 个周期的 KDJ 表 |
| 多周期共振要手动切图对照 | 月/周/日/120/60/30/15 分钟并排在同一行 |
| "放量"全凭印象，没有量化标准 | 变异系数 CV + 放量倍数，可排序、可横向比较 |
| 板块热度只看涨幅榜，看不到资金 | 主力净流入占全市场比例，连续 4 天趋势 |
| 消息面靠刷手机，不知道是不是真在升温 | 48 小时资讯量 vs 前两周日均，给出升温倍数 |
| 每天重复同样的操作 | 每交易日 11:40 和 15:15 自动生成 |

## 读完之后你能做到

**使用**

1. 看懂四张表每一列的口径和含义
2. 用 Excel 筛选排序，从全市场缩到 20~50 只候选
3. 判断哪些数据可信、哪些要打折扣（空值、截断、同名误命中）
4. 知道午盘批和收盘批为什么数不一样

**维护**

5. 知道参数改在 `radar/config.py` 的哪一行
6. 会用 `--limit 30` 做链路自检
7. 看得懂日志，能区分"网络问题"和"代码问题"
8. 会装、会停 launchd，会确认它有没有跑

## 四个支柱

```text
好用的行情雷达 = 口径清楚的指标 + 可验证的数据 + 稳定的调度 + 看得懂的表
```

缺任何一项，它都会在某个交易日安静地给出错误结论，而你不会察觉。

## 边界

这套系统**只做数据加工**。不给买卖建议，不接交易接口，不对行情做任何预测。

KDJ 金叉、放量、资金流入，都是**对已经发生的事情的统计描述**，不含未来信息。

```text
产出是候选池，不是决策。决策永远在你这一侧。
```

把这条记牢，后面所有关于"这个指标准不准"的疑问会少一半。
